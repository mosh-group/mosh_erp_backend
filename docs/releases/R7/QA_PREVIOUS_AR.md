### ما ثبت بتجربة الواجهة مع الخادم الفعلي
- إنشاء حساب موظف/مهمة جديدة عبر API، تسجيل الدخول والتحميل.
- عدم وجود بصمة لا يمنع الاستلام والبدء ولا ينشئ بصمة افتراضية.
- الاستلام لا يبدأ التنفيذ.
- وقت الجلسة مولَّد ومحفوظ في الخادم وتعرضه الواجهة.
- 2 دقيقة + توقف 10 دقائق + 3 دقائق = 5 دقائق تنفيذ.
- استراحة إضافية لا تدخل في التنفيذ؛ استئناف دقيقة إضافية يعطي 6 دقائق.
- القراءة من API ثم إعادة إنشاء الواجهة بالكامل لا تفقد الوقت؛ لا يعتمد حفظ مدة المهمة على تخزين محلي في المتصفح.
- الإرسال للمراجعة يوقف الجلسة ويحفظ إجماليها.
- مهمة اختبار قديمة ذات بداية صفر تُظهر الحاجة للمراجعة؛ الإصلاح الصريح يحفظ بداية جديدة ويحافظ على الإجمالي المعروف.
- فترة بلا بداية محفوظة لا تُحوّل إلى صفر تاريخي ولا إلى مدة متخيلة؛ تبقى فجوة مراجعة.
- «لا يوجد عمل لدي» وإنهاء يوم العمل لا يضيفان مدة إلى تنفيذ المهمة.
- أزرار الإيقاف والاستئناف داخل تفاصيل المهمة تستعمل الخادم نفسه وتعود بوقت محفوظ.

## حدود بيئة الاختبار — مهم
الاختبار هنا ليس بديلاً عن Staging مطابق لسيرفرك:
- مجلد المستخدم يطلب PHP `^8.5` في composer.json. المتاح هنا PHP 8.4.23، بينما مكتبة Laravel المرفقة 13.32.0 تقبل هذا التشغيل. استُخدمت نسخة اختبار خاصة مع تجاوز حارس إصدار autoload فقط لتشغيل الفحوص؛ **لم تتغير متطلبات Composer ولا vendor في الحزمة المسلَّمة**. يلزم إعادة الاختبارات بإصدار PHP المعتمد عندك.
- ملحق `pdo_sqlite` غير متاح هنا. استُخدم محول PDO خاص بالمختبر يمرر أوامر Laravel/Eloquent إلى محرك SQLite حقيقي عبر Python. عمليات SQL والمعاملات والحفظ ليست ردود API وهمية، لكن هذا لا يختبر مشغل PDO الأصلي أو قفل الصفوف في MySQL/PostgreSQL عندك. المحول غير موجود ضمن ملفات النشر، ولا يعتمد عليه التطبيق.
- DOM وBCMath غير متاحين. شُغّل PHPUnit برمجياً دون قراءة XML، مع تعطيل إخراج HTML لطرفية المختبر فقط. هذه التغييرات لم تُضمَّن في ملفات الإنتاج.
- فحص المتصفح استخدم Chromium وملفات الواجهة الفعلية كاملة، مع تحميلها داخل صفحة معزولة وإرسال طلباتها إلى Laravel المحلي عبر ناقل HTTP اختباري. لم تُختبر طبقة HTTPS/reverse proxy أو سياسات Cookies/CORS في الدومين الحقيقي؛ جلسة Laravel والتحقق من CSRF استُخدما على مسار HTTP المحلي.
- الساعة مُتحكم بها لتجربة فترات محددة وقابلة للتكرار. لم يُترك التطبيق أياماً أو يُجرَ اختبار ضغط إنتاجي. منع مهمتين نشطتين فُحص تسلسلياً ومعاملاتياً، وليس عبر عمال إنتاج متزامنين.
