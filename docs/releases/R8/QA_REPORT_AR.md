## حدود المختبر — ضروري
بيئة المستخدم الموثقة PHP 8.5، بينما المتاح هنا PHP 8.4.23. لم يغير التسليم متطلبات PHP ^8.5 أو composer أو vendor. فقط نسخة مختبر منفصلة تجاوزت حارس autoload لتشغيل الاختبارات.
لم يتوفر pdo_sqlite الأصلي في المختبر؛ استُخدم جسر PDO اختباري إلى SQLite عبر Python. أُجريت عمليات Laravel/SQL والمعاملات على بيانات اختبار معزولة، لكن هذا ليس فحصاً لمشغل PDO الأصلي في جهاز المستخدم.
DOM وBCMath غير متوفرين بالمختبر؛ شُغّل PHPUnit دون إعداد XML الأصلي. ملفات الجسر والتجاوز و.env الاختبارية وقاعدة الاختبار غير موجودة في مجلدي التسليم.
لم يُجرَ اختبار ضغط أو عمال متزامنين إنتاجياً، أو HTTPS/CORS/Cookies مع السيرفر الحقيقي. التوقيت حتمي في الاختبارات وليس تشغيل أيام متواصلة.
