# MOSH ERP R12 — فحص مرفقات المهام

## المصدر
- الأساس: R11_LOGIN_FEEDBACK_FULL.
- لم تُعدّل قواعد البيانات أو `.env` أو `APP_KEY` أو `config.js` أو `storage` أو `vendor`.

## التعديل
- توحيد مرفقات إنشاء المهمة إلى زر/منتقي عام واحد.
- توحيد مرفقات محادثة المهمة إلى زر/منتقي عام واحد.
- إزالة `accept=image/*` و`accept=video/*` من منتقي المهمة حتى يظهر منتقي الملفات العام.
- تحقق الواجهة من الامتداد والحجم قبل الرفع.
- Backend يقبل قائمة مرفقات شائعة حسب الامتداد ويستمر بمنع الملفات التنفيذية والسكربتات.
- حد الحجم بقي 25 MB لكل ملف.
- المرفقات غير القابلة للمعاينة داخل المتصفح تُعامل كملف عادي بدلاً من محاولة عرضها كصورة/فيديو.

## الفحوص المنفذة
- `node --check`: جميع ملفات JavaScript التطبيقية (62) دون أخطاء صياغة.
- Node regression suite: 38/38 ناجح.
- Browser R12: نجاح منتقي المرفق العام وقبول JPG/PNG/MOV/MP4/PDF/DOCX/ZIP/PSD/DWG ورفض HTML والملف الأكبر من 25 MB، دون page errors.
- Browser R10 preload regression: 0 preload warnings، 0 preload nodes، وجميع 60 سكربت manifest حُمّلت مرة واحدة وبالترتيب.
- `php -l` على FileController: ناجح.
- SQLite `PRAGMA quick_check`: ok على قواعد SQLite الأربع المرفقة.
