اختبارات R33 — تشغيل معزول، وليس على بيانات الشركة
================================================
run_isolated.py ينسخ المشروعين إلى مجلد مؤقت قبل تشغيل مجموعات الاختبار المحددة.
نتائج الاختبارات تكون في مجلد output تختاره خارج المشروع الأصلي.
المتطلبات: Python وPlaywright/Chromium وbeautifulsoup4 وrequests، وPHP CLI وNode.
هذه اختبارات محلية للمطور؛ المستخدم لا يحتاج تشغيلها لتركيب تحديث الواجهة.

مثال من مجلد المشروعين على جهاز تطوير:
python MOSH_LARAVEL_BACKEND/tests/R33/run_isolated.py --output /path/outside/project/qa-r33

الواجهة الأصلية وملفاتها وapi-boot وapi-client تُختبر في Chromium.
النقل الحقيقي المحدود: HTTP إلى PHP محلي مع ChunkStorage للتحقق من تجميع المرفقات.
الحسابات والمهام وبيانات IT والموارد البشرية في الاختبارات مصطنعة.
لا تشغّل ملفات الاختبار عبر استضافة عامة، ولا توجّهها إلى API الشركة.
هذه المجموعة لا تختبر جلسة Laravel أو CSRF أو SQL الفعلي ولا Instagram الحقيقي.
لا تشغّل اختبارات PHPUnit العامة على قاعدة العمل.
نسخ تقارير الإصدارات السابقة الموجودة في الحزمة سجلات تاريخية وليست نتائج R33.
